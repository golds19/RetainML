# RetainML: MLOps Customer Churn Prediction System

An end-to-end MLOps platform for predicting customer churn with AI-powered retention recommendations.

## Overview

RetainML is a machine learning system that predicts customer churn and generates personalized retention strategies. The project demonstrates MLOps practices including automated pipelines, continuous training, and intelligent model deployment.

## Getting Started

### Prerequisites
- Python 3.10 or higher

### Installation

1. Clone the repository
2. Create and activate virtual environment:
   ```bash
   python -m venv .venv
   source .venv/bin/activate  # On Windows: .venv\Scripts\activate
   ```
3. Install dependencies:
   ```bash
   uv add -r requirements.txt
   ```
